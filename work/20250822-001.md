## 3. 약국 영업시간 정보 조회 검토

### 조사 내용
현재 사용 중인 HIRA 약국정보서비스 API에서 영업시간 정보 제공 여부 확인

### 분석 결과

#### HIRA API (현재 사용 중)
- **영업시간 정보 없음** ❌
- 제공 필드: 약국명, 주소, 전화번호, 좌표, 개설일자 등
- `operatingHours` 필드는 모델에만 존재, API에서 미제공

#### 대안 검토
1. **국립중앙의료원 API**
   - 부분적 영업시간 정보 가능성
   - QT 파라미터로 진료요일 검색만 가능

2. **응급의료정보 API** (참고)
   - 병원/응급실은 영업시간 정보 제공
   - `dutyTime1s ~ dutyTime7s`: 요일별 시작/종료 시간

### 권장사항
- 약국 영업시간은 별도 데이터 소스 필요
- Supabase DB에 수동 관리 고려
- 추후 국립중앙의료원 API 통합 검토
